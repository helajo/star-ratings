# Daily Technical Star Rating

Daily MACD / RSI / Bollinger / Volume-OBV star ratings for an AI-infrastructure and Nasdaq-100 stock
universe, published as a GitHub Pages site. Generated every US trading day by the
[ai-infra-prices](https://github.com/helajo/ai-infra-prices) workflow; this repo holds only the rendered pages.

- **Latest:** https://helajo.github.io/star-ratings/latest.html
- **Archive:** https://helajo.github.io/star-ratings/ (one page per trading day)

Ratings are a structured description of what each indicator shows, in the star language of the
four-category handbook, not a forecast. Prices via Nasdaq historical quotes; not investment advice.
